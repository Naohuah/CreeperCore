# 设计系统 · 明亮、直接、以启动为中心

> 这一版界面推翻了 M0 初版的深色“世界线控制台”。原因不是审美疲劳，而是真实反馈：在任务栏和 1320×840 的窗口里，大面积的苔藓绿让层级糊在一起，装饰性模块挤占了最重要的“开始游戏”。最终方向回到 PCL2 式的直接：明亮、中性、信息清楚，苦力怕只在需要被认出的地方出现。

## 设计目标

1. **启动是唯一首屏任务。** 打开启动器后，不需要理解仪表盘、评分环或快捷卡片，直接看到当前版本和启动按钮。
2. **颜色为含义服务。** 绿色表示主操作、当前版本和正常运行；蓝色表示信息与 Fabric；琥珀表示需要注意；红色只用于危险操作。
3. **可读性优先。** 使用系统 UI 字体与高对比度文字，不再用 8–9px 的英文像素标签承担关键信息。
4. **少一层容器。** 能用一个平面表格表达的内容，不做卡片套卡片。
5. **保留苦力怕身份，但不让角色压过工具。** 像素脸缩到标题栏、侧栏账户、启动卡片和图标尺度。

- 不使用整屏深色背景，也不使用荧光苦力怕绿。
- 主按钮的白色文字在深绿底上保持足够对比度；辅助文字最深降到 `--text-3`，不再使用浅灰浮在白色上。
- 导航图标使用低饱和的多色区分：启动绿、版本蓝、下载青、模组琥珀、备份紫灰、设置灰绿，但不做强装饰。

- 标题栏 38px，侧栏 156px，内容最大宽度 1080px，居中于主区域。
- 默认窗口 1000×640，最小 920×600；比初版明显紧凑，仍能完整放下版本表格的操作列。
- 页面边距 20–24px；表格与白面板共用 9px 圆角和 1px 边框。
- 侧栏不再铺满整高的白色面板：导航和账户贴着顶部，下方由 3D 皮肤预览填补，不会形成一整块空侧栏。
- 小于 980px 时侧栏折叠为图标栏，3D 预览随之隐藏；桌面窗口使用 920px 的最小宽度。

## 字体与层级

- 正文：系统 UI 字体，13.5px；标题 24px / 650。
- 表格：表头 11px，正文 12–12.5px，次要信息 10.5–11.5px。
- 等宽只用于版本号、文件路径、控制台日志，不再用于装饰性英文小标题。
- 中文界面，所有按钮与状态使用玩家能直接理解的词；加载器名称保留 Fabric / Forge 等专有名词。

## 组件

- **面板**：白色平面 + 细边框 + 很轻的阴影；没有内发光、扫描线或背景粒子。
- **数据表**：版本、下载、模组、备份统一使用网格行。表头淡灰，当前行淡绿，危险操作右侧收敛。
- **按钮**：主操作为深绿实心，次操作为白底描边，弱操作为透明文字；图标按钮只保留在行尾。
- **表单**：标签、控件、说明统一垂直排列；设置页以分隔线组织，不再把每个设置做成独立卡片。
- **对话框**：浅色背景 + 半透明遮罩；启动日志使用浅灰终端样式，错误行用红色文本，而不是整屏黑底。
- **动效**：只保留页面淡入、对话框上浮和进度条；`prefers-reduced-motion` 下全部降级。

## 页面

### 启动

单列，不设仪表盘：

1. 版本下拉与加载器、Java、内存、账户元信息；
2. 主启动按钮与打开目录；
3. 一行运行状态，点击打开检查面板；
4. 已安装版本列表（最多 6 行）；
5. 四个文本快捷入口。

不再有巨型苦力怕、评分环、快捷操作网格和重复的 CTA。

### 社区资源设置

设置页新增“社区资源”面板：

- **来源**：Modrinth 官方 / MCIM 镜像；
- **Mod 简介**：说明中文简介由 MCIM 翻译接口提供，失败回退英文；
- 镜像只代理搜索和版本元数据，文件仍从 Modrinth CDN 下载；
- 下载页右上角来源标记会同步显示 `MODRINTH` 或 `MCIM`。

### 玩家档案

首次启动不创建任何离线账户，也不自动选中一个虚构玩家：

- 侧栏账户卡显示“未选择账户”；
- 启动页按钮变成“创建账户”，点击打开账户弹窗；
- 账户弹窗空状态提示先创建离线档案；
- 创建后立即写入配置并自动选中，后续启动直接使用。

### 启动后生命周期

启动成功后启动器与游戏进程解耦：

- 关闭启动器窗口会退出启动器本体，但不会结束 Minecraft；
- 启动器只在窗口存在期间收集日志和崩溃信息，关闭后不依赖后台保活；
- 默认不自动最小化；需要时可以开启“启动后最小化”；
- 启动器内“停止游戏”仍然可用。

### 启动过渡

启动不是一个纯日志弹窗，而是一段有明确状态的过渡：

- **启动中**：苦力怕传送门环、粒子、扫描进度条；只显示最新启动步骤，不再铺一块空日志区；
- **启动成功**：苦力怕图标弹出，绿色勾选落下，粒子向外扩散；1.9 秒后自动收起到游戏悬浮条，并保留“启动成功”通知；
- **启动失败**：切回完整的日志与诊断结果，不隐藏错误；
- 所有动画支持 `prefers-reduced-motion` 降级。

### 侧栏 3D 皮肤

账户卡下方的剩余空间是一块约 138×210px 的皮肤展示区：

- 使用 **skinview3d + Three.js** 在 WebGL canvas 中渲染标准 64×64 皮肤；
- 默认没有皮肤：显示“未设置皮肤 / 导入本地皮肤”的占位卡，不伪造一个默认角色；
- 有皮肤时保持待机姿势，不自动旋转；鼠标拖动可手动旋转，滚轮缩放和右键平移被关闭；
- 离线账户可导入自己的 PNG 皮肤（64×64、64×32、128×128），以 data URL 存在本机 `localStorage`，按账户 UUID 隔离；
- 本地皮肤会在启动离线版本时生成 `resourcepacks/CreeperCore Skin.zip`，替换默认 Steve/Alex 纹理，并写入 `options.txt`；只对本地客户端生效；
- Microsoft 账户登录后自动下载并缓存正版在线皮肤；本地导入作为覆盖层，有覆盖时出现“恢复在线皮肤”按钮；
- 导入失败、尺寸不符或 WebGL 不可用时给出明确提示；
- 窗口宽度小于 980px（侧栏折叠为图标栏）时隐藏预览，避免挤压头像区域。

离线账户没有在线皮肤，因此默认不展示任何角色。Microsoft 账户的在线皮肤来自正版档案，本地覆盖仍然可用。

### 资源包 / 光影 / 数据包

下载页顶部补了 **资源包 / 光影 / 数据包** 三个分类：

- 资源包安装到 `resourcepacks`；
- 光影安装到 `shaderpacks`；
- 数据包安装到 `datapacks`，并提示单个世界使用时需要移动到存档的 `datapacks`；
- 这三类搜索按目标 Minecraft 版本过滤，不要求 Fabric/Forge 加载器；
- 安装后保留一条结果条，显示文件名、目标目录和“打开文件夹”，结果行变为“已安装”；
- 简介仍复用中文翻译层。

### 玩家档案

账户弹窗改成与 PCL2 类似的两栏结构：

- 顶部只有“正版 / 离线”两个标签；
- 中央显示账户头像、名字和账户类型；
- 正版页只保留一个 Microsoft 登录按钮；
- 离线页只保留新账户输入框；
- 多账户时才显示紧凑切换列表；
- 不再堆放 UUID、长说明和重复的账户卡片。

### Microsoft 登录

账户弹窗支持离线档案与 Microsoft 正版登录：

- 内嵌 WebView 窗口加载 Microsoft 官方登录页，OAuth 授权码 + PKCE，不把 Microsoft 密码输入启动器；
- Microsoft token → Xbox Live → XSTS → Minecraft Services；
- 读取正版 UUID、角色名与在线皮肤，按账户缓存；
- 保存 Microsoft refresh token，启动前按需刷新；
- 游戏参数使用 `--userType msa`、Minecraft accessToken 与角色 UUID；
- 外置 authlib 登录已移除，旧账户在配置迁移时清理。

### 启动页

启动页只保留两列：

- 左侧紧凑版本列表，当前版本淡绿底；
- 中央头像、账户名、启动按钮和当前版本；
- 运行状态缩成一行，点击打开检查面板；
- 下载、版本管理、模组、备份、目录、日志收进图标工具栏。

不再在启动页重复“已安装版本”表和页头说明；完整版本管理仍在版本页。

### 版本

路径条 + 搜索/筛选 + 单张版本表。每行显示版本、加载器、Java、状态和操作。当前版本用淡绿底和勾选标记，不额外插入卡片。

### 下载

下载页去掉了大标题和说明段，顶部只保留一行 **游戏 / Mod / 整合包** 标签和来源；下面是一块紧凑的筛选面板，搜索框占主宽度，安装操作退到结果行右侧。整体参考 PCL2 的“先筛选、再看结果”的密度，不再用大标题和提示段落占垂直空间。

游戏版本：原版 / Fabric / Forge / NeoForge 分段切换 + 搜索 + 正式版 / 快照筛选 + 紧凑版本表。正式版行不再重复“正式版”标签，版本号、日期和状态靠左成组，行高 44px，安装操作贴右；快照才显示类型标签。安装进度由右下角浮层承载。

Forge / NeoForge 不手写版本 JSON：下载官方 installer，在游戏根目录创建 `launcher_profiles.json`，用 Java 17+ 运行 `--installClient`，再由引擎扫描安装器生成的新版本。OptiFine 暂未接入。

Modrinth 模组：

- 目标版本只列出已安装的 Fabric / Quilt / Forge / NeoForge 版本；
- 搜索按目标游戏版本和加载器做服务端筛选，不把不兼容的模组摆到玩家面前；
- 结果行显示图标、作者、简介、下载量、更新时间和加载器标签；
- 简介通过 MCIM 翻译接口获取中文并缓存，接口失败时回退英文原文；标题保留作者原标题；
- 点击结果行打开详情，列出当前目标版本可安装的版本、发布类型、文件大小和必需依赖；
- 详情提供“转到 Modrinth”“转到 MC 百科”和“复制名称”；外链只允许白名单站点；
- 选中的版本如果含必需前置，会显示“前置资源”面板，列出项目名和图标；安装时自动补齐；
- 可以选择指定版本安装，而不是只下载最新版；
- 安装选定版本时自动解析必需依赖；
- 文件下载后先做 SHA-1 校验，再原子写入版本对应的 mods 目录；
- 不会静默覆盖同名文件；已存在且校验一致则跳过，冲突时给出提示；
- 原版目标版本会直接引导去安装模组加载器。

Modrinth 整合包：

- 只支持 Fabric 基础版本，目标下拉只显示已安装的 Fabric；
- 安装时读取 `.mrpack` 的 `modrinth.index.json`，复制基础 Fabric 配置并生成新的 `pack-*` 版本；
- 新版本强制开启隔离，游戏目录是 `versions/<pack-id>/game`，不改动基础 Fabric 版本；
- 每个文件校验 SHA-1 / SHA-512；同名文件不会被静默覆盖；
- 抽取 `overrides/` 与 `client-overrides/`，忽略服务端覆盖；
- Forge / NeoForge / Quilt 整合包在索引校验阶段直接拒绝，不留下半安装实例。

### 模组

版本上下文条 + 问题提示 + 搜索/筛选 + 模组表。依赖缺失和重复 ID 直接贴在对应行，不做统计卡片。

### 备份

版本上下文条 + 备份表。创建、恢复、删除都在同一张表里；恢复前自动安全备份仍是硬规则。

### 设置

账户、Java、游戏目录、启动参数、下载与关于六个分区。使用一个纵向滚动面，按分隔线分组；关于页并入设置底部。

## 已删除的东西

- 独立“首页 / 控制台”及 `#/home` 入口；
- 独立“关于”页与导航项；
- 巨型苦力怕 hero、坐标装饰、引信/粒子、扫描线；
- Creeper Sense 的大评分环、四条统计卡、快捷操作网格；
- 版本卡片瀑布流、下载页的 spotlight/侧栏、模组页的统计卡；
- Silkscreen 像素字体与大量 8–9px 英文眉题。

诊断、备份、模组依赖检查等功能没有删除，只是从首屏移到需要时打开的面板或对应页面。

## 苦力怕身份

- 标题栏 21px 像素脸；
- 侧栏账户卡 28px；
- 启动卡 58px；
- 侧栏账户卡和启动页当前版本卡使用同一张皮肤头像：有本地皮肤或 Microsoft 在线皮肤时显示 8×8 面部裁切，否则回退到苦力怕图标；
- 3D 皮肤只在用户导入或 Microsoft 登录同步后出现；
- 应用图标独立设计（见下）；
- 其余配色、圆角和间距保持中性，让角色成为识别点，而不是背景噪声。

## 应用图标

应用图标和启动页、标题栏、账户卡使用**同一个 CreeperMark**：同样的 16×16 纹理、同样的边缘透明度和同样的脸部坐标。应用图标不再使用单独的深色圆角底板。

- 1024px 主图直接从 CreeperMark 的像素网格生成；
- 16 / 20 / 24 / 32 / 40 / 48 / 64 / 128 / 256 每个尺寸独立成帧，使用最近邻缩放保持像素边缘；
- 边缘单元按 UI 中的透明度叠在深色底上，因此缩小后自带一圈很薄的深色描边；
- 窗口启动时再次 `set_icon`，绕过 Explorer 可能缓存的旧资源。

## 可访问性

- 正文、按钮与状态文字使用深色前景；不使用亮绿字配白底。
- 所有交互控件保留 `:focus-visible` 边框。
- 导航、表格操作和对话框按钮保留文字标签；仅图标按钮提供 `aria-label` / `title`。
- 页面标题、数据表头、表单标签使用语义元素。
- 支持减少动态效果偏好。

## 取舍

- 当前只实现明亮主题，不提供主题切换。
- 桌面优先，不追求手机布局；窗口最小宽度 920px。
- 信息密度高于初版，但用表格与留白保持可扫读性。
- 不使用图片背景、装饰插画或英雄区；视觉识别主要交给图标、苦力怕像素脸和绿色强调。
